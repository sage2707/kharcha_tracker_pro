Kharcha Tracker
A clean and minimal expense tracking application built using React, TypeScript, Vite, Tailwind CSS, and shadcn/ui. Designed for speed, simplicity, and a distraction-free user experience.
# Kharcha Tracker
Live Demo: https://kharcha-tracker-pro-tott.vercel.app/

Overview
Kharcha Tracker helps users record their daily expenses with a smooth interface and zero complexity. The app focuses on usability and clean UI patterns, making it ideal for quick financial logging without unnecessary features or bloat.

Features
	•	Add, view, and delete expenses
	•	LocalStorage-based data persistence
	•	Fully responsive layout
	•	Modular and scalable component structure
	•	Fast development and production builds via Vite
	•	Styled using Tailwind CSS and shadcn/ui for consistent design

Tech Stack
	•	React
	•	TypeScript
	•	Vite
	•	Tailwind CSS
	•	shadcn/ui
	•	ESLint & Prettier
	•	Node.js + npm

Usage
	1.	Add an expense with amount, category, and description.
	2.	View your entries instantly in a clean list.
	3.	Remove any entry as needed.
	4.	Data is stored locally on the device using LocalStorage.
	5.	Designed to provide a smooth and fast personal finance experience.
